# CS-305-Portfolio

# Briefly summarize your client, Artemis Financial, and its software requirements. Who was the client? What issue did the company want you to address?
Artemis Financial is a global financial consulting company that will work with clients with creating financial plans for their personal needs. The company wants to make sure that the application and APIs created for Artemis Financial have top-notch security. It will be important to encrypt the data in communications with their clients as they contain highly sensitive information regarding the finances and personal information of both the client and Artemis Financial.

# What did you do well when you found your client’s software security vulnerabilities? Why is it important to code securely? What value does software security add to a company’s overall well-being?
I did well in the code review and identifying flaws with existing code. It was easy to follow with the given flowchart of security flaws to consider and address. Making sure to do industry standard best practices is essential so that security problems are addressed. Most often, a developer is not working alone, so being purposeful and thoughtful with how code is written is important so that vulnerabilities aren’t introduced by multiple parties. Especially when working with a company like Artemis Financial, clients’ personal information and sensitive financial information is worked with, so it is essential to make sure their data is secure. Clients need to have trust that their info is safe, otherwise, Artemis Financial would lose their customer base.

# Which part of the vulnerability assessment was challenging or helpful to you?
The flowchart made the vulnerability assessment more straightforward and helpful. It was challenging to address secure API interactions, as it was mostly out of my control. The Spring Framework handled most of the heavy lifting, so it was more of a trust exercise to make sure that the application was secure on that end. Research and keeping up to date with vulnerabilities will be extremely important for a developer when considering vulnerabilities. It will also be important to identify false positives that could arise during the assessment.

# How did you increase layers of security? In the future, what would you use to assess vulnerabilities and decide which mitigation techniques to use?
Using the cipher was my favorite way to increase layers of security. Encryption and decryption is important to use throughout software security, such as sending a digital signature to ensure that a file hasn't been manipulated, or an encrypted hash to make sure an attacker is unable to view data in transit. The Java Docs contain a large amount of ciphers available to developers to encrypt their data. It will be important to keep up to date with modern encryption techniques, as new standards arise often, as old techniques are broken or out-of-date. Just 20 years ago, a completely different cipher was the standard, until engineers "broke" it.

# How did you make certain the code and software application were functional and secure? After refactoring the code, how did you check to see whether you introduced new vulnerabilities?
The dependency report was used to make sure the application is secure, while code reviews were conducted to make sure the application was functional. It is important to cross reference the dependency check before and after any changes to see if new vulnerabilities were introduced during the process. While code reviews were conducted individually, when on a team, it will be important to look over your peers' work to see if any flaws could be found in the code, as many security risks happen through careless coding.

# What resources, tools, or coding practices did you use that might be helpful in future assignments or tasks?
The Maven Dependency Check, alongside the NVD API for vulnerabilities, will be extremely important in checking the most up-to-date vulnerabilities. It will also be important to check patch notes and updates for any tools or libraries that are used, aside from just the Spring Framework. Conducting research to find the most secure tools and libraries will be very important, especially when working for a high-profile business like Artemis Financial.
